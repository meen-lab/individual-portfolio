## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser or use Live Server.

Alternative:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
