# Portfolio Blog — Yasmeen Halema

## Project Title
Yasmeen Personal Portfolio Blog — a responsive, professional portfolio and blog site created with HTML, CSS, and JavaScript.

## Description
This repository contains a four-page personal portfolio website built for a university GitHub portfolio assignment. It showcases skills, projects, a short blog, and a contact form with validation.

## Features
- Responsive layout (Flexbox & CSS Grid)
- Mobile navigation menu
- Dark mode toggle (persisted in `localStorage`)
- Smooth scrolling and scroll-to-top button
- Contact form validation using JavaScript
- Clean, modern design using the specified color palette

## Technologies Used
- HTML5 (semantic)
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript

## How to Run
1. Clone or download the repository.
2. Open `index.html` in your browser, or serve with a static server (recommended for local testing).

Example using Python HTTP server:
```
cd portfolio-blog
python -m http.server 8000
```
Then visit `http://localhost:8000`.
